# SIH-TEAM-BYTEXX

## ByteX DSS — Multi-Hazard Emergency Relocation & Decision Support System

An intelligent, GIS-enabled Disaster Decision Support System built for District Emergency Operations Centres (DEOC) to manage multi-hazard threats (flash floods, debris flows, landslides, and cloudbursts).

### Key Modules
- **GIS Operations Console**: Spatial mapping of hazard zones, isolation diagnostics, and live route status.
- **Village Risk Matrix**: Mathematical risk scoring factoring in hazard exposure, structural vulnerability, demographic dependence, and isolation coping deficits.
- **Safe Shelters Network**: Capacity tracking, intake absorption, medical triage availability, and logistics headroom.
- **Phased Evacuation Plans**: Dynamic convoy transit scheduling (<6h, 6–24h, 24–72h) with automated bus fleet assignments.
- **Disaster Stress Simulator**: Interactive sandbox for climatic anomalies and road disruption simulations.
- **Alert Center**: CAP ITU-T X.1303 multi-channel broadcast engine (WhatsApp, SMS, Cell-Broadcast, FM Radio, PA Sirens).

- **Tech Stack**: Next.js 14 (App Router), React 18, TypeScript, Tailwind CSS
- **Theme Engine**: Adaptive Command Center Dark Mode & High-Contrast Light Mode with instantaneous client-side switching and persistent storage
- **Mapping**: Leaflet, OpenStreetMap / Mappls
- **Icons & Data**: Lucide React, Recharts
